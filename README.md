# NavSight

Prévia web demonstrativa do projeto NavSight — orientação escolar acessível por mapa virtual e áudio.

## Como executar

1. Extraia o arquivo ZIP.
2. Abra a pasta `NavSight`.
3. Abra o arquivo `index.html` em um navegador atualizado.

## Observações

- O site é uma demonstração front-end autocontida; não requer instalação de dependências.
- O cadastro e o login desta versão usam `localStorage` do navegador e não representam autenticação segura nem banco de dados real.
- As posições e os ambientes do mapa são ilustrativos. Substitua-os pela planta oficial da escola antes de utilizar o mapa como orientação real.
- O áudio utiliza a API de síntese de voz disponível no navegador.
